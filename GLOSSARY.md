# CSV Analyzer

A tool for importing CSV files into a browser-local PostgreSQL database and exploring them with SQL. All data lives in the user's browser; nothing is stored server-side.

## Language

### Import pipeline

**Upload**:
Selecting or dropping a CSV file into the app. An upload alone changes nothing in the database.
_Avoid_: Import (when meaning file selection)

**Processing**:
Parsing and validating an uploaded CSV, and deriving its table name from the file name. Processing never touches the database.
_Avoid_: Loading

**Import**:
Turning a processed CSV into a table in the database. An import never silently replaces an existing table; a name collision is surfaced to the user to resolve.
_Avoid_: Load, ingest

### Database

**Database**:
The PostgreSQL database running in the user's browser; its tables exist only in that browser.
_Avoid_: Server, backend

**Table**:
A PostgreSQL relation created by one CSV import.
_Avoid_: Dataset, sheet

**Table name**:
The name a table is imported under, derived from the CSV file name: lowercased, with separators replaced.
_Avoid_: File name (they diverge after import)

**Type inference**:
The app's assignment of PostgreSQL column types to a CSV's columns based on the values they contain.
_Avoid_: Casting

**Inferred primary key**:
The primary key an imported table gets: a CSV column that reads as an identifier, or a generated `csv_id` column when none does.
_Avoid_: Row id

**Table schema**:
The column-level shape of one table: column names, types, nullability, and primary key.
_Avoid_: Schema (alone) — collides with the PostgreSQL schema namespace

### Exploring data

**Query**:
SQL executed against the database, whether written by the user or generated by the app.
_Avoid_: Search

**Preview**:
A kind of query the app generates to sample a table's rows; previews are queries, not a separate concept.
_Avoid_: Table view

**Sample query**:
A ready-made query the app fills into the editor and runs to demonstrate query execution.
_Avoid_: Template query
